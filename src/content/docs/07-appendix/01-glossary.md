用語は製品・文献によって意味が異なることがあります。ここでは本書での使い方を短く整理します。厳密な条件や実装差は各章を参照してください。

## ストレージとインデックス

| 用語 | 本書での意味 |
| --- | --- |
| ブロック／ページ | DBMSがI/O、キャッシュ、チェックサムなどを管理する固定サイズの単位。製品によって呼称が異なる |
| レコード | 論理行をストレージ形式へ符号化したもの。ヘッダー、NULLビットマップ、バージョン情報などを含み得る |
| ヒープファイル | キー順を維持せずレコードをページへ格納する基本構造。優先度キューのヒープとは別 |
| スロットページ | スロット配列から可変長レコードのオフセットを参照し、レコードIDを維持したままページ内再配置できる形式 |
| レコードID / TID | ページIDとスロットIDなどから物理レコードを指す識別子 |
| エクステント | 連続ページをまとめた割り当て単位 |
| 空き領域マップ | 空き領域を持つページを探すための補助構造 |
| バッファプール | ストレージ上のページをメモリフレームへキャッシュするDBMS内部領域 |
| バッファフレーム | バッファプール内で一つのページを保持するメモリスロット |
| 固定 | 使用中ページが置換されないようフレームを固定すること |
| 未書き出しページ | メモリ上で更新済みだがデータファイルへ未書き出しのページ |
| キャッシュヒット / ミス | 必要ページがバッファプールにある／ストレージから読む必要がある状態 |
| 置換方針 | バッファプールが満杯のとき追い出すフレームを選ぶ規則。LRU、時計など |
| 順次I/O | 近接ページを順に読むI/O |
| ランダムI/O | 離れたページへ移動しながら読むI/O |
| B-木 | 高分岐数の平衡探索木。製品名としてB+木的構造もB-木と呼ぶ |
| B+木 | 項目を葉へ集め、葉をキー順にリンクした多分探索木 |
| 分岐数 | 一つの内部ノードが持つ子数。大きいほど木の高さを抑えられる |
| ページ分割 | 満杯ノードを複数ページへ分け、親へ区切りを追加する処理 |
| クラスタ化インデックス | 表行の物理配置と強く結びつくインデックス。具体的意味は製品差が大きい |
| セカンダリインデックス | 主系/クラスタ化アクセス経路以外の検索経路 |
| 複合インデックス | 複数列を順序付きキーとして持つインデックス |
| カバリングインデックス | クエリに必要な列を含み、表アクセスを省略できる可能性があるインデックス |
| インデックスのみの走査 | 表行本体を読まず、インデックスと可視性情報から結果を返す走査 |
| 部分インデックス | 述語を満たす行だけを含むインデックス |
| ハッシュインデックス | ハッシュ関数でバケットを選び、主に等値参照を行うインデックス |
| 衝突 | 異なるキーが同じハッシュバケット/スロット候補へ対応すること |
| LSM-木 | メモリの整列済み構造と不変整列済みファイルをマージする書き込み-指向構造 |
| Memtable | LSM-木が新しい書き込みを受けるメモリ上の整列済み構造 |
| SSTable | キー順に並んだ不変ファイル（整列済み文字列表） |
| コンパクション | 複数のSSTable／ランをマージし、バージョン、削除マーカー、配置を整理する処理 |
| 削除マーカー | 不変構造で削除を表す印 |
| Bloomフィルター | 「確実に存在しない」を判定でき、陽性には偽陽性を許す確率的集合 |
| 読み取り増幅 | 一つの論理読み取りで余分に読むページ/ファイル/バイト |
| 書き込み増幅 | アプリケーションの論理書き込みに対しストレージへ実際に書くバイトの倍率 |
| 容量増幅 | 有効論理データに対する実ストレージ使用量の倍率 |
| 行指向 | 一行の列を近くへ配置するストレージ形式 |
| 列-指向 | 同じ列の値をまとめるストレージ形式 |

## トランザクションと並行性

| 用語 | 本書での意味 |
| --- | --- |
| トランザクション | 複数読み取り/書き込みを一つのコミット/中止単位として扱うもの |
| ACID | 原子性、整合性、分離性、永続性 |
| 原子性 | トランザクションの変更を全か無かにする性質 |
| 整合性（ACID） | トランザクション前後で定義された不変条件を守る性質 |
| 分離性 | 並行するトランザクションの相互作用を制御する性質 |
| 永続性 | コミット済み結果を対象障害後も保持する性質 |
| スケジュール / 履歴 | 複数トランザクション操作の時系列 |
| 直列化可能性 | 並行実行結果が何らかの直列注文と同等である性質 |
| 厳格直列化可能性 | 直列化可能性に実時間順序を加えた性質 |
| ダーティリード | 未コミット値を別トランザクションが読む異常 |
| 反復不能読み取り | 同一トランザクションの同じ行再読み取りで値が変わる異常 |
| ファントムリード | 述語再実行で一致行集合が変わる異常 |
| 更新消失 | 同じ古い値から計算した書き込みで一方の更新が失われる異常 |
| 読み取りスキュー | 複数項目から新旧の混ざった状態を読む異常 |
| 書き込みスキュー | 同じスナップショットを読んだトランザクションが別行を更新し、不変条件を壊す異常 |
| スナップショット分離 | 一貫したスナップショットを読み、書き込み-書き込み競合を防ぐが書き込みスキューを許し得る分離性 |
| 共有ロック | 読み取り用でほかの共有ロックと共存できるロック |
| 排他ロック | 書き込み用で共有／排他ロックと競合するロック |
| 意図ロック | 下位粒度へロックを取る意図を上位へ記録するロック |
| 2PL | 拡大段階でロックを取得し、縮小段階で解放する二相ロック |
| 厳格二相ロック | 書き込みロックをコミット/中止まで保持する2PL |
| 述語/範囲ロック | 述語に該当する現在・将来の行範囲を保護するロック |
| デッドロック | トランザクションの待機関係が循環になり誰も進めない状態 |
| MVCC | 複数バージョンからスナップショットに可視なバージョンを選ぶ並行性制御 |
| 可視性 | あるスナップショットからレコードバージョンが見えるかという規則 |
| 不要版の回収 / GC | 不要古いバージョンを回収する処理 |
| 悲観的制御 | 競合を予想し、操作前にロック/資源を確保する方式 |
| 楽観的制御 | 競合が少ないと仮定し、コミット前にバージョン/依存を検証する方式 |
| SSI | スナップショット間の危険依存関係を検出しSerializableを作る方式 |
| 直列化障害 | 安全な直列順序を作れずトランザクションを中止したエラー |

## 障害回復

| 用語 | 本書での意味 |
| --- | --- |
| WAL | データページより先に復旧ログを永続化する先行書き込みログ |
| ログレコード | 更新、コミット、チェックポイントなどをWALへ記録した単位 |
| LSN | ログシーケンス番号。WAL内の位置・順序 |
| ページLSN | ページへ反映済みの最新ログ位置 |
| 再実行 | コミット済みなど必要な変更をログから再適用すること |
| 取り消し | 未コミット変更を取り消すこと |
| フォース / フォースなし | コミット時にデータページ本体の書き出しを要求する／しない方針 |
| スティール / スティールなし | 未コミット未書き出しページをストレージへ書き込みできる／できない方針 |
| グループコミット | 複数トランザクションのコミットを一度のWAL書き出しへまとめること |
| チェックポイント | 復旧開始を新しくするため実行中/未書き出し状態などを記録する処理 |
| ファジーチェックポイント | トランザクションを止めず、変化中の状態を記録してページを徐々に書き出すチェックポイント |
| ARIES | 分析、再実行、取り消しでスティール/フォースなしDBを回復する代表的アルゴリズム |
| CLR | 取り消し進捗を記録する補償ログレコード |
| クラッシュ復旧 | データ/WALストレージが残るプロセス／OSクラッシュから戻す処理 |
| 媒体障害 | データファイル/WAL自体を失う・破損する障害 |
| PITR | ベースバックアップとWALアーカイブから指定時点へ戻す時点復旧 |
| RPO | 許容できるデータ損失の時間・位置 |
| RTO | 許容できるサービス復旧時間 |

## 分散データベース

| 用語 | 本書での意味 |
| --- | --- |
| レプリケーション | 同じ論理データの複製を複数ノードへ維持すること |
| リーダー / フォロワー | 書き込み順序を決めるノード／リーダー ログを追従するノード |
| 同期レプリケーション | コミット前に指定レプリカの確認応答を待つ複製 |
| 非同期レプリケーション | レプリカの確認応答を待たず、リーダーでのローカルコミットを返す複製 |
| レプリカ遅延 | リーダー位置とレプリカ受信/書き出し/再生位置の差 |
| 線形化可能性 | 操作がリクエスト-応答間の一点で起き、実時間順序を守るように見える性質 |
| 結果整合性 | 新しい書き込みが止まればレプリカが最終的に収束する性質 |
| 因果整合性 | 先行発生関係のある操作順を守る性質 |
| 書き込み後の読み取り保証 | セッションが自分の完了済み書き込み以降を読む保証 |
| 単調読み取り | 一度読んだバージョンより古いバージョンへ戻らない保証 |
| クォーラム | Nレプリカ中R/Wなど一定数の応答/確認応答を要求する方式 |
| 読み取り時修復 | 読み取り時にレプリカ差を見つけ、古い複製を修復すること |
| 不整合の定期修復 | バックグラウンドでレプリカ差を比較・修復すること |
| ヒント付き引き渡し | 停止中の対象レプリカに代わり別ノードが書き込みを一時保持すること |
| フェイルオーバー | 障害時に待機系/フォロワーを新しい主系/リーダーへ切り替えること |
| フェンシングトークン | 古い所有者/リーダーの遅れて到着した操作を拒否する単調増加トークン/世代 |
| スプリットブレイン | 複数ノードが同時に正当なリーダーとして書き込みを受ける状態 |
| CAP | ネットワーク分断時に線形化可能整合性と可用性を同時に常時満たせないこと |
| PACELC | パーティション時のA/Cに加え、通常時の遅延時間/整合性トレードオフを表す考え方 |
| 合意 | 障害下で一つの決定/順序付けられたログへ合意する問題 |
| 状態機械レプリケーション | 同じコマンドログを決定論的状態機械へ適用してレプリカ状態を一致させる方式 |
| Raft任期 | リーダーの世代を表す単調増加論理時計 |
| Raftコミット済み位置 | クラスターがコミット済みと認識し適用可能なログ接頭辞位置 |
| 過半数 | ⌊N/2⌋+1ノード。異なる過半数同士が必ず交差する |
| 分割 | 論理データ集合を複数部分へ分割すること |
| シャーディング | 水平パーティションを複数ノードへ配置すること |
| シャードキー | データ配置とリクエスト振り分けを決めるキー |
| パーティション刈り込み | 述語から不要パーティションを除外すること |
| 分散問い合わせと集約 | 複数シャードへリクエストを分岐数し結果を集約すること |
| コロケーション | 関連データを同じパーティション/ノードへ置くこと |
| グローバルセカンダリインデックス | 基底データとは別分割で全シャードを横断するインデックス |
| 再均衡化 / 再シャーディング | パーティション所有権や境界を変更しデータを移動すること |
| 集中箇所 / 偏り | データ量または負荷が一部パーティション/キーへ偏ること |
